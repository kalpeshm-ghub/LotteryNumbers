how to delete a github repository

---

To delete a GitHub repository:

1. Go to your repository on GitHub.com
2. Click **Settings** (top tab bar)
3. Scroll to the bottom — **Danger Zone** section
4. Click **Delete this repository**
5. Type the repository name to confirm, then click the delete button

**Via GitHub CLI:**
```bash
gh repo delete OWNER/REPO-NAME --yes
```

**Via GitHub API:**
```bash
curl -X DELETE -H "Authorization: token <your_token>" https://api.github.com/repos/OWNER/REPO-NAME
```

Note: You need admin permissions on the repository to delete it. Deletion is permanent and cannot be undone.

how to create a workflow to upload DEV repo changes to azure

---



Here's a GitHub Actions workflow to run Terraform for your DEV environment on push:

**1. Create the workflow file:**

```
azure-terraform-appservice-test/.github/workflows/dev-deploy.yml
```

```yaml
name: Deploy DEV

on:
  push:
    branches: [dev]
    paths:
      - 'DEV/**'

permissions:
  id-token: write
  contents: read

jobs:
  terraform:
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: DEV

    steps:
      - uses: actions/checkout@v4

      - uses: azure/login@v2
        with:
          client-id: ${{ secrets.AZURE_CLIENT_ID }}
          tenant-id: ${{ secrets.AZURE_TENANT_ID }}
          subscription-id: ${{ secrets.AZURE_SUBSCRIPTION_ID }}

      - uses: hashicorp/setup-terraform@v3

      - run: terraform init
        env:
          ARM_CLIENT_ID: ${{ secrets.AZURE_CLIENT_ID }}
          ARM_TENANT_ID: ${{ secrets.AZURE_TENANT_ID }}
          ARM_SUBSCRIPTION_ID: ${{ secrets.AZURE_SUBSCRIPTION_ID }}
          ARM_USE_OIDC: true

      - run: terraform plan
        env:
          ARM_CLIENT_ID: ${{ secrets.AZURE_CLIENT_ID }}
          ARM_TENANT_ID: ${{ secrets.AZURE_TENANT_ID }}
          ARM_SUBSCRIPTION_ID: ${{ secrets.AZURE_SUBSCRIPTION_ID }}
          ARM_USE_OIDC: true

      - run: terraform apply -auto-approve
        env:
          ARM_CLIENT_ID: ${{ secrets.AZURE_CLIENT_ID }}
          ARM_TENANT_ID: ${{ secrets.AZURE_TENANT_ID }}
          ARM_SUBSCRIPTION_ID: ${{ secrets.AZURE_SUBSCRIPTION_ID }}
          ARM_USE_OIDC: true
```

**2. Azure setup — create a Service Principal with OIDC (federated credentials):**

```bash
# Create an App Registration
az ad app create --display-name "github-terraform-deploy"

# Create a Service Principal
az ad sp create --id <APP_ID>

# Assign Contributor role on your subscription
az role assignment create --assignee <APP_ID> \
  --role Contributor \
  --scope /subscriptions/5eda6671-3913-45cf-bca3-629eab15dd36

# Add federated credential for GitHub Actions
az ad app federated-credential create --id <APP_ID> --parameters '{
  "name": "github-dev-branch",
  "issuer": "https://token.actions.githubusercontent.com",
  "subject": "repo:kalpeshm-ghub/azure-terraform-appservice-test:ref:refs/heads/dev",
  "audiences": ["api://AzureADTokenExchange"]
}'
```

**3. Add GitHub secrets** (repo → Settings → Secrets → Actions):

| Secret | Value |
|--------|-------|
| `AZURE_CLIENT_ID` | App Registration's Application (client) ID |
| `AZURE_TENANT_ID` | `8d2a4415-c4e6-4336-93d6-d430fd8c48a0` |
| `AZURE_SUBSCRIPTION_ID` | `5eda6671-3913-45cf-bca3-629eab15dd36` |

**4. Recommended:** Move your Terraform state to a remote backend (Azure Storage) so the workflow and your local machine share the same state. Add this to your DEV `main.tf`:

```hcl
terraform {
  backend "azurerm" {
    resource_group_name  = "rg-apac-vero-non-prod-management-aue-01"
    storage_account_name = "<your_storage_account>"
    container_name       = "tfstate"
    key                  = "dev.terraform.tfstate"
  }
}
```
